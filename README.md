# demogit

`demogit` is demo git temporary. This repository contains an ASP.NET MVC application targeting the .NET Framework. The documented project target is .NET Framework 4.5.

## Folder Structure

```text
README.md                   Repository onboarding documentation
demogit/
├── demogit.sln             Visual Studio solution
└── demogit/                ASP.NET MVC web application project
    ├── Controllers/        MVC controllers
    ├── Views/              Razor views and shared layouts
    ├── App_Start/          Startup, routing, bundling, filters, and Web API configuration
    ├── Content/            CSS stylesheets and static content
    └── Scripts/            JavaScript assets
```
